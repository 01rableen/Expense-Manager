# Expense Manager

A full-stack web application to track daily expenses, categorize spending, and visualize your budget with interactive charts.

## Features
- Add expenses with details
- Delete expenses
- Categorize spending
- View spending summary
- Donut chart for category breakdown
- Bar graph for expense trends
- Secure user authentication and authorization

## Tech Stack
- Backend: Java, Spring Boot
- Security: Spring Security, JWT, BCrypt
- Database: MySQL
- Frontend: HTML, CSS, JavaScript
- Charts: Chart.js

## How to Run
1. Clone the repo
   git clone https://github.com/01rableen/Expense-Manager.git
2. Open in IntelliJ IDEA
3. Set up MySQL database and update application.properties with your DB credentials
4. Run the project
5. Open http://localhost:8080 in your browser
